# ContactFormApp

A simple, professional, and easy-to-use contact form built with ASP.NET Core Razor Pages.  
Ideal for websites that need a contact form with database storage, validation, and a modern UI.

---

## Features

- Clean, responsive homepage with hero section, feature cards, and call-to-action
- Fully functional contact form
- Client-side and server-side validation
- Saves messages to SQL Server database
- Light blue background with hover effects on cards
- Easy to integrate into any website
